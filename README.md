# Teste GitHub Live

Este é um aplicativo web monolítico de lista de tarefas (to-do list) para uso pessoal. Ele consiste em um frontend React que interage com um backend Node.js/Express, utilizando SQLite para persistência local dos dados das tarefas. A arquitetura foca na simplicidade e na execução local para gerenciar tarefas diárias.

## Stack Tecnológica
- **Frontend:** React
- **Backend:** Node.js/Express
- **Banco de Dados:** SQLite

## Pré-requisitos
- Node.js (versão 14 ou superior)
- npm (gerenciador de pacotes do Node.js)

## Como Instalar Dependências

### Backend
Navegue até o diretório `backend/` e execute:
```bash
npm install
```

### Frontend
Navegue até o diretório `frontend/` e execute:
```bash
npm install
```

## Como Rodar em Desenvolvimento

### Backend
Navegue até o diretório `backend/` e execute:
```bash
npm start
```
O backend será iniciado na porta 3001 (ou outra porta configurada).

### Frontend
Navegue até o diretório `frontend/` e execute:
```bash
npm start
```
O frontend será iniciado na porta 3000 (ou outra porta configurada) e abrirá automaticamente no seu navegador.
